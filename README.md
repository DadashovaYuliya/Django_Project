# ИНТЕРНЕТ-МАГАЗИН

## Описание:

Проект интернет-магазина, создаваемый с помощью фреймворка Django.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:DadashovaYuliya/Django_Project.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Маршрутизация

1. Настроена маршрутизация для страниц home и contacts.

## Контроллеры

1. Создан контроллер для отображения домашней страницы (home).
2. Создан контроллер для отображения страницы с контактной информацией (contacts).
